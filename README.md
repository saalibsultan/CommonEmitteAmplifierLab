# Common-Emitter Amplifier Lab

Overview
Documentation and measurement log for a Common-Emitter BJT amplifier circuit using voltage divider biasing. This repository contains laboratory setup details, theoretical parameters, and empirical measurements recorded using hardware trainer modules and standard bench equipment.

Specifications & Components
- Supply Voltage (VCC): 12 V[cite: 2]
- Base Resistors: R1 = 22 kohm, R2 = 4.7 kohm[cite: 2]
- Collector Resistor (RC): 1 kohm[cite: 2]
- Emitter Resistor (RE): 470 ohm[cite: 2]
- Transistor Parameters: beta_dc = 150, beta_ac = 160[cite: 2]

Equipment
- Analog Electronics Trainer Board / Modular Circuit Panel
- DC Power Supply
- Function Generator
- Oscilloscope
- Digital Multimeter[cite: 2]
